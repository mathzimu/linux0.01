# Minimal Linux 0.01 Equivalent Kernel - 需求规格说明书 (SRS)

## 1. 引言

### 1.1 项目目标
实现一个可引导、功能等价于1991年Linux 0.01的极简操作系统内核，用于研究、教学和验证目的。

### 1.2 约束条件
- **架构**: i386 (Intel 80386) 仅限
- **运行环境**: QEMU / Bochs 仿真环境
- **工具链**: gcc + as (GAS) + ld (Docker固定环境)
- **代码量**: ≤ 15,000 LOC
- **语言**: C + x86 GAS汇编 (AT&T语法)

### 1.3 参考基准
- Linux 0.01 原始源码 (Linus Torvalds, 1991)
- Tanenbaum MINIX 设计原则
- i386 程序员参考手册

## 4. 排除项 (明确不包含)

| # | 特性 | 说明 |
|---|------|------|
| E1 | TCP/IP网络栈 | 超出0.01范围 |
| E2 | 设备驱动模块化 (LKM) | 0.01无此功能 |
| E3 | SMP/多核支持 | 仅单核i386 |
| E4 | 虚拟文件系统 (VFS) | 直接使用Minix |
| E5 | 动态链接库 | 无 |
| E6 | 用户态/内核态内存保护 | 已实现（页表 U/S 隔离，越权访问 → page fault panic） |
| E7 | 写时复制 (COW) | 0.01未实现 |
| E8 | 信号量/POSIX IPC | 超出范围 |
| E9 | ELF加载器 | 仅支持ELF32格式（不支持a.out） |
| E10 | 图形模式/GUI | 仅VGA文本模式 |
| E11 | 浮点运算支持 | 不实现 |
| E12 | 电源管理/ACPI | 超出范围 |

## 5. 验证标准

1. **QEMU引导测试**: 内核成功引导至shell提示符
2. **多进程测试**: 同时运行3个并发进程
3. **系统调用测试**: fork/read/write/open/close/getpid正常工作
4. **键盘输入测试**: 键盘输入正确回显
5. **文件读取测试**: 从Minix文件系统读取文件
6. **内存压力测试**: 分配/释放页面无泄漏
