# §10 内存管理 — `mm/memory.c` · `mm/page.s`

> 常量：`include/linux/mm.h` — `LOW_MEM=0x100000`，`PAGE_SIZE=4096`，`USED=100`

## 1. 全局

```c
unsigned long memory_end;
unsigned long *mem_map;   // 放在物理内存高端
int max_map_nr;
```

`MAP_NR(addr) = (addr - LOW_MEM) >> 12`

## 2. `mem_init(start_mem, end_mem)`

1. `max_map_nr = (end_mem - LOW_MEM) / PAGE_SIZE`
2. `mem_map` 放在 `end_mem - map_size`，全部置 0
3. `mem_map[0]=mem_map[1]=USED` — 页目录、页表0
4. 标记 `mem_map` 自身占用页为 USED
5. 标记 `[LOW_MEM, start_mem)` 内核映像为 USED

`main` 传入：`start_mem = &_end + 0x1000`，`end_mem ≤ 4MB`。

## 3. `get_free_page`

线性扫描第一个 `mem_map[i]==0`，置 1，地址 `LOW_MEM + i*PAGE_SIZE`，`memset` 清零。失败返回 0。

用于：`sys_fork` 分配 PCB 页等。

## 4. `free_page`

检查范围、页对齐；`mem_map[i]<=0` 或 `>=USED` 则拒绝；否则 `--`。

## 5. `free_page_tables`

- `from` 须 4MB 对齐  
- 遍历 PDE，释放 PTE 指向页与页表页，清 PDE  
- `write_cr3(read_cr3())` 刷 TLB  

本仓库用户地址空间切换场景几乎未用。

## 6. `page.s` + `do_no_page`

```as
page_fault:
  // 取错误码、CR2
  call do_no_page
```

```c
void do_no_page(...) { panic("page fault"); }
```

**无按需调页。** 访问未映射地址（>4MB 或 PDE 无效）即 panic。

## 7. 与 buffer / malloc 的边界

| 分配器 | 位置 | 释放 |
|--------|------|------|
| 页框 `get_free_page` | mem_map | `free_page` |
| buffer 缓存 | `buffer_init` 在高端切出，并标 USED | 不还回页分配器 |
| `lib/malloc` | bump from `_end+0x40000` | 无 free |

三者**无统一堆**，见 LIMITATIONS.md。
