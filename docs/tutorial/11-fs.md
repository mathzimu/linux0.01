# §11 文件系统 — `fs/*`

> 布局：MINIX v1 · 头文件 `include/linux/fs.h` · 设备读 `drivers/hd.c`

## 1. 模块地图

| 文件 | 职责 |
|------|------|
| `minix.c` | 全局表、`get_super`、`sys_setup` |
| `buffer.c` | 块缓存、`bread`/`getblk`/`brelse`、`sleep_on`/`wake_up` |
| `bitmap.c` | `new_block`/`free_block`/`new_inode`/`free_inode` |
| `inode.c` | `iget`/`iput`/`read_inode`/`get_empty_inode`（pipe inode 槽） |
| `namei.c` | 路径 → inode（相对路径从 current->pwd，绝对从 root/chroot） |
| `file_dev.c` | `file_read`/`file_write`（zone 映射） |
| `pipe.c` | `sys_pipe`/`read_pipe`/`write_pipe`（0.01 移植） |

## 2. 磁盘布局（MINIX v1）

```
块0  引导
块1  超级块 (magic 0x137F)
块2..  inode 位图 (s_imap_blocks)
接着  zone 位图 (s_zmap_blocks)
接着  inode 表
接着  数据区 (s_firstdatazone 起)
```

块大小 `BLOCK_SIZE=1024`。

## 3. `minix.c` — `sys_setup`

```c
dev = 0x301;              // 主硬盘第1分区习惯编号
bh = bread(dev, 1);
sb = (minix_superblock *)bh->b_data;
// 校验 SUPER_MAGIC
// 拷贝字段到 super_block[0]
brelse(bh);
printk(..., super_block[0].s_magic);  // 用已拷贝字段，勿用释放后的 sb
```

全局：`super_block[]` `inode_table[]` `file_table[]`。

## 4. `buffer.c` — 块缓存

### 初始化 `buffer_init(buffer_end)`

- 在 `buffer_end` 以下放置 `NR_BUFFERS` 个 `buffer_head` + 数据区  
- 空闲环：`b_prev_free`/`b_next_free`  
- hash 桶清空  
- 将缓存占用页在 `mem_map` 标 USED  

`main` 调用：`buffer_init(memory_end - 0x100000)`。

### `getblk(dev,block)`

1. hash = `(dev^block)&(NR_BUFFERS-1)` 查找  
2. 命中则 `b_count++`  
3. 否则在 free 环找 `b_count==0`，填入 dev/block，挂 hash  
4. 没有则 `schedule(); goto repeat`

### `bread`

`getblk` → 若未 uptodate → `ll_rw_block(READ)` → `wait_on_buffer`。

### `ll_rw_block`

**仅 READ：** `lba = blocknr * 2`（1K 块 = 2 扇区），`hd_read_sectors`。写请求直接 return。

### `sleep_on` / `wake_up`

隐式等待链（见 PREREQ-os-theory）。`wake_up` 只置 RUNNING，不清空指针（实现较简）。

## 5. `bitmap.c`

| 函数 | 位图起点 |
|------|----------|
| inode 位图 | 块 `2 + i` |
| zone 位图 | 块 `2 + s_imap_blocks + ...` |
| `free_inode` | **必须** `2 + (i_num-1)/(BLOCK_SIZE*8)`，**不能**加 `s_imap_blocks` |
| `free_block` | `2 + s_imap_blocks + bit/...` |

## 6. `inode.c`

- `iget`：缓存命中 `i_count++`；否则占空槽 `read_inode`（复用脏槽前先 `write_inode`）  
- `get_empty_inode`：占 inode_table 空槽（不读盘，pipe 用）  
- `read_inode`：按 imap+zmap 后算块号，拷贝 `d_inode`→`m_inode`；bread 失败则 `i_dev=0;i_count=0`  
- `iput`：pipe inode 在最后一个引用释放时 `free_page` 缓冲页；普通 inode `i_count--`，
  为 0 且 `i_nlinks==0` 则 `free_inode`

## 7. `namei.c`

- 根 inode 号 = 1，`dev=0x301`  
- 目录项：`inode(2) + name[14]`  
- `name_eq`：先比字符；`j==14 || de_name[j]=='\0'`（**先判 j==14 防 OOB**）  
- `next_entry`：直接 zone[0..6]，间接 zone[7]

## 8. `file_dev.c`

- `bmap` 风格：zone[0..6] 直接，[7] 一级间接，[8] 二级  
- `file_read`：按 `f_pos` 读块，`put_fs_byte` 到用户缓冲  
- `file_write`：可 `new_block`；但底层 `ll_rw_block` 不写盘，脏数据难持久化  

## 9. 打开文件路径（端到端）

```
sys_open(path)
  → namei → 逐级 find_entry → iget
  → file_table 槽 + filp[fd]
sys_read(fd)
  → file_read → bread → ll_rw_block → hd_read_sectors
sys_close
  → f_count-- → iput
```
